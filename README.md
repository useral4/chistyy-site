# KinavaPro

Проверка публичных сайтов на юридические недостатки и технические SEO-проблемы.

57 проверок: 26 юридических и 31 SEO. Проверяются главная страница, локальные JavaScript-файлы, связанные документы и вложенные ссылки, до 3 страниц контактов/заказа, robots.txt и sitemap.xml. Чистая браузерная сессия проверяет появление cookie-баннера и запуск аналитики до согласия. Найденные проблемы и непроверяемые процессы разделены; для последних есть свёрнутый блок с пояснениями. Суммы санкций — условный справочный сценарий без повторного подсчёта составов.

Штрафы и SEO считаются отдельно. В каждом разделе до 5 проблем — все открыты бесплатно; от 6 — первые 3 открыты. Пакеты на 30 дней: «Один сайт» 179 ₽ / 1 домен, «Специалист» 390 ₽ / 10 доменов, «Агентство» 999 ₽ / 30 доменов. Перепроверки добавленных доменов не расходуют лимит и не продлевают срок; купленные снимки остаются доступны после окончания пакета. Ручные проверки и бесплатные отчёты не расходуют лимит. Цена, лимит, срок и закрытые данные проверяются сервером. Реальные платежи отключены; используется тестовый API ЮKassa.

Доступ хранится в HttpOnly cookie и восстанавливается по личной закрытой ссылке в разделе «Мой доступ». Знание домена не даёт доступ к чужим пакетам. Старые оплаченные ссылки автоматически получают доступ к своему домену до 30 дней от прежней оплаты, без продления. Записи пакетов лежат в `REPORTS_DIR/passes`; сохраняйте весь `REPORTS_DIR` на постоянном диске и в резервной копии. Файловое хранилище рассчитано на один процесс сервера; для нескольких реплик нужна БД с транзакционным списанием лимита.

## Запуск

Node.js 24. Установите зависимости и запустите:

```sh
npm install
npm start
```

Адрес: http://localhost:4173 . Переменная PORT задаёт другой порт. Тесты: npm test. Альтернатива установки: pnpm install --frozen-lockfile.

## Настройка

См. [SETUP.md](SETUP.md): тестовая ЮKassa (Shop ID 1485993), webhook, выдача отчёта и отправка по email, постоянное хранение, SMTP, Метрика, Вебмастер, выбор VPS и ограничения аудита. Шаблон переменных — [.env.example](.env.example). Приложение читает переменные окружения; пример сам по себе настройки не активирует.

Заявки сначала сохраняются вне public/, затем отправляются сотруднику при настроенном SMTP. Неудачное уведомление не удаляет заявку. На Render для постоянного хранения нужен persistent disk. Документы privacy/consent/cookies — проекты тестовой версии; рабочие параметры инфраструктуры и хранения ещё должен подтвердить оператор.

Не публикуйте реальные персональные данные до настройки подходящего хранения, сроков удаления и уведомлений. Корректность договорных и правовых сценариев не устанавливается одним HTML-аудитом.
